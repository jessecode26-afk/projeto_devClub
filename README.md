# 🚀 Gerador de Landing Pages com IA

Um projeto web que utiliza inteligência artificial para gerar **landing pages completas e estilizadas automaticamente** a partir de uma descrição de negócio fornecida pelo usuário.

O sistema envia o prompt para a API da **Groq** e retorna uma página pronta em **HTML + CSS**, exibindo:

- 📄 Código gerado em tempo real
- 👀 Preview instantâneo da página
- ⚡ Resposta rápida com IA
- 🎨 Layout criativo e visual moderno

## ⚙️ Como executar o projeto

### 1. Clone o repositório

```bash
git clone https://github.com/SEU-USUARIO/projeto_devClub.git
```

---

### 2. Abra o projeto

Basta abrir o arquivo:

```bash
index.html
```

---

### 3. Configure sua API Key

No arquivo `scripts.js`, substitua:

```javascript
"Authorization": "Bearer SUA_CHAVE_AQUI"
```

pela sua chave da API Groq:

```javascript
"Authorization": "Bearer gsk_..."
```

Você pode gerar sua chave em:

https://console.groq.com

---

## 🔐 Segurança

**Importante:**  
Nunca envie sua API Key para o GitHub.

Este projeto é apenas para fins de estudo.  
Em aplicações reais, o ideal é proteger a chave usando backend e variáveis de ambiente.
